gpu-telemetry-stack

Production-grade GPU observability for Kubernetes. DCGM hardware metrics, eBPF pod-to-pod TCP latency, Prometheus SRE alerts and a Grafana dashboard — in one umbrella Helm chart.

View on GitHub Install index.yaml

Install

Add the repository and install the chart.

helm repo add gpu-telemetry-stack https://victorbecerragit.github.io/k8s-gpu-telemetry-stack
helm repo update

# GKE — GKE manages the NVIDIA driver and device plugin
helm install gpu-telemetry gpu-telemetry-stack/gpu-telemetry-stack \
  -n gpu-telemetry --create-namespace \
  -f https://raw.githubusercontent.com/victorbecerragit/k8s-gpu-telemetry-stack/main/charts/gpu-telemetry-stack/values-gke.yaml

# EKS — the GPU Operator installs drivers
helm install gpu-telemetry gpu-telemetry-stack/gpu-telemetry-stack \
  -n gpu-telemetry --create-namespace \
  -f https://raw.githubusercontent.com/victorbecerragit/k8s-gpu-telemetry-stack/main/charts/gpu-telemetry-stack/values-eks.yaml

What's inside

Five components, wired together and tested as a unit.

DCGM exporter

SM utilization, VRAM, PCIe TX/RX, temperature and XID errors straight from the GPU.

eBPF probes

Kernel-level TCP round-trip histograms between pods. No sidecars, no proxies.

Prometheus

kube-prometheus-stack plus five GPU and network SRE alert rules.

Grafana

The GPU Telemetry — Fleet & Network dashboard, auto-provisioned.

GPU Operator

NVIDIA driver and device plugin for EKS. Disabled on GKE, which manages its own.

GKE demo

Terraform + scripts that stand up a disposable cluster and capture real telemetry.

Alerts

Thresholds are configurable under prometheus.rules.thresholds.

AlertSeverityTrigger
GpuXidErrorcriticalAny new DCGM_FI_DEV_XID_ERRORS in 5m
GpuThermalThrottlingwarningGPU temp > 85 °C for 5m
GpuVramExhaustionwarningVRAM > 90 % for 10m
GpuNotReportingcriticalDCGM scrape target down 5m
GpuPodTcpLatencyHighwarningp99 pod-to-pod TCP RTT > 5000 µs for 10m

Requirements

Kubernetes

1.27 or newer.

GPU nodes

NVIDIA device plugin present (GKE managed, EKS via GPU Operator).

Prometheus Operator

CRDs installed by the bundled kube-prometheus-stack.

eBPF

Kernel ≥ 5.4 and privileged pods for the tracing DaemonSet.
